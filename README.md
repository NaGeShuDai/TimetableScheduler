# 空课与排班

## 模板与安装版（1.2.0）

空课表导出使用 `resources/free_template.xlsx`，只填写 C2:I21 的名单，不修改模板其他内容。校区、部门在人员详情设置。每位学生占一行，内容使用模板中的仿宋_GB2312 字体；字体文件位于 resources。若在其他电脑用 Excel 查看，需要先安装该字体，才能以相同字体呈现。

总空课表文件名为“2026-2027学年第1学期校新媒体空课表.xlsx”，周表为“第1周空课表.xlsx”。模板固定五个节次，模板导出按这五个节次的标准时间计算，不使用自定义排班时段。

`TimetableScheduler.exe` 为独立便携程序，资源已嵌入。旁边放 resources 文件夹时优先读取该文件夹，便于替换模板。

`TimetableScheduler-Setup.exe` 为安装程序，可选择安装位置并创建快捷方式。安装版数据存储于 `%LOCALAPPDATA%/TimetableScheduler/data`，便携版仍使用程序旁的 data 目录。

仓库不包含本地人员数据和个人课表示例。字体为用户提供的资源，其使用与分发需符合字体原有许可。

双击 `TimetableScheduler.exe` 运行，不需要安装 Python。

## 三个页面

1. 人员与课表：批量导入海南大学格式的 `.xls` 或 `.xlsx`，查看每位人员的课程、待确认信息及参与状态。
2. 空课表：选定教学周后，按原课表星期列和节次行展示整段空闲人员；导出 `.xlsx`。
3. 排班表：配置每格人数，生成建议，点击格子从候选人员下拉列表中替换。右侧规则面板可以隐藏。

项目附带 `examples/sample_20243006951.xls`，来自提供的课表。普通导入自动参与计算；表底文字直接忽略。仅解析异常需手动核实确认。

## 2026-10-14 更新

- 人员与课表新增“增加课程”：选定学生，输入课程名称、周次、星期、时间和地点。手动课程随项目保存并参与全部计算；重新导入替换该人员时会一起被替换。
- “时段设置”支持默认/自定义切换。自定义每行 `名称 | HH:MM-HH:MM`，允许 1～24 个时段；保存默认模式时仍保留自定义方案。课程占用使用原始实际时间。
- 切换或修改时段会清空旧排班、重置人数，并停用绑定具体节次的规则。这些规则需重新选择节次并启用。
- 空课表页面可选择“总空课表”，设置汇总周次（默认 1-18），每人独立一行，格式如 `Name (1-9, 12, 14-18)`。导出按钮导出当前选择的本周或总空课表。
- 总空课表中的括号表示该人员在该星期、该完整时段空闲的教学周；没有空闲周次的人员不显示。

## 排班规则

自定义规则支持禁止安排、固定安排、优先安排，可指定人员、星期、节次和周次（如 `1-5,7-10`），可排序、编辑、删除、启停。

禁止与固定是强制约束。课程冲突和重叠排班不能被规则覆盖；互相冲突的强制规则会报错。自定义“优先安排”严格按列表顺序先优化，再依次优化默认规则：人数覆盖、总时长均衡、晚班均衡、周末均衡、减少一天多班。

每个优化阶段最多 5 秒。若达到时限，会保留有效方案并显示尚未证明最优，后续目标不会覆盖前面的优先级。相同输入采用单线程确定性计算。

手动修改不会自动挪动其他格子。固定规则不能通过手动编辑绕过。允许保留空缺；缺员用红色边框提醒。撤销、重做和恢复建议均按当前教学周独立记录。

黄色边框代表与建议结果不同的格子，绿色背景表示本次新加入的人员，橙色姓名表示总工时超过可参与人员平均值加提醒阈值。绿色背景和橙色文字可以同时出现。公平性是提醒，不会禁止手动安排。被规则排除全部班次的人不纳入平均值。默认阈值 100 分钟，可以修改。

## 时间与导入边界

- 按教学周计算，不需要第一周日期。当前版本不处理假期调休、实际日期、通勤、个人请假及历史跨周工时。
- 星期六日与中午默认不排班，可在“班次人数”中启用；默认周一至周五白天和晚间每格 1 人。
- 节次排序和表格形状沿用源文件，午间行位于晚间行之后。
- 本文件晚间整行包含第 9～11 节，部分课程只有第 9～10 节。因缺少单节作息，全部按原行时间保守占用，不会将可能有课的时间误报为空闲。
- “时段设置”修改的是排班与空闲查询时段，课程时间保持导入文件中的原始时间。
- 表底信息直接忽略，不显示、不参与计算。如需占用时间，使用“增加课程”补充。
- 解析异常人员默认不能参与计算；核实并补齐课程后可以在详情中手动确认。
- 同一工作区只接受同一学期，按文件名中的学号识别重复人员；没有学号时按姓名识别，请为同名人员提供含学号的文件名。
- 只支持所验证的星期网格导出格式，不保证兼容其他学校所有模板。
- 导出是当前教学周的一张静态表，UI 高亮和规则不会嵌入导出的工作簿。

## 数据与源代码

数据自动保存到 EXE 同目录的 `data/workspace.json`。复制或备份此目录即可备份人员、规则与排班。运行目录需要可写。不要同时打开多个实例修改同一数据文件。

`app.py` 是 Tkinter 界面，`core.py` 是解析和排班逻辑；`test_core.py` 验证导入、周次、约束、优先级、均衡、缺员和导出。

安装 Python 3.12 后，可用 PowerShell 运行 `build.ps1` 重新打包。源码启动：`.venv/Scripts/python.exe app.py`。
