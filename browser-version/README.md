# 海南大学空课与排班系统 · 本地浏览器免环境版

这是桌面课表与排班程序的浏览器版本。课表解析、空闲统计、建议排班、Excel 导出均由浏览器完成。本地 Node.js 服务只提供静态文件，不接收或保存课表数据，无数据库、无 Python 后端、无登录和云端同步。

## 一、最快启动方法（Windows）

1. 将项目文件夹放在固定位置，例如 `D:\HNU-BrowserScheduler`。不要只解压其中的 `public` 文件夹。
2. 本包已附带 Windows x64 的 Node.js 运行文件，无需安装 Node.js、Python、npm 或其他开发环境。适用于 Windows 10/11 x64 和近期版本的 Edge、Chrome、Firefox；Windows 自带的 Edge 即可使用。
3. 双击 `Start-Browser.cmd`。程序会隐藏启动本地静态服务并打开默认浏览器。
4. 地址为 `http://127.0.0.1:8765`。首页点击“进入系统”，也可直接点击顶部三个页面入口。
5. 如需桌面快捷方式，双击 `Create-Shortcut.cmd`。它会在桌面和项目目录创建 `HNU Browser Scheduler.lnk`，使用本项目图标。以后直接双击快捷方式启动。

交付包已经包含构建好的页面、前端库、字体、模板与 `runtime/node.exe`。**完整解压后即可双击启动，不需要安装环境，也不需要联网。** 请保留 runtime 文件夹；不要只发送 HTML 文件。收件人应收到 `HNU-BrowserScheduler-Portable.zip` 并自行完整解压。

移动项目文件夹后，请重新运行 `Create-Shortcut.cmd`，更新快捷方式中的绝对路径。交付机器上已经创建的 `.lnk` 只适用于原路径，其他电脑应重新生成。

## 二、手动部署与停止

在项目目录打开 PowerShell，执行：

```powershell
.\runtime\node.exe --version
.\runtime\node.exe server.cjs
```

看到 `本地浏览器版：http://127.0.0.1:8765` 后，在浏览器打开该地址。手动启动时需要保留终端；按 Ctrl+C 停止服务。

一键启动的服务在后台运行。关闭网页不会停止服务，双击 `Stop-Browser.cmd` 可停止默认端口上的本地服务。停止服务不会清除浏览器里的数据。电脑重启后重新双击启动快捷方式即可。

如 8765 端口被其他程序占用，可在 PowerShell 使用其他端口：

```powershell
$env:PORT = '8766'
.\runtime\node.exe server.cjs
```

然后访问 `http://127.0.0.1:8766`。一键启动和停止脚本使用固定端口 8765；其他端口请手动启动和 Ctrl+C 停止。

**更换端口、更换浏览器、使用 localhost 替代 127.0.0.1 都会进入另一份浏览器存储。** 更换前先备份数据，更换后恢复备份。

不要直接双击 `public/index.html`：文件协议下的模板读取和计算 Worker 无法可靠运行，需要通过本地 HTTP 服务打开。

## 三、人员与课表

1. 在“默认导入部门”选择部门，再点击“批量导入”，一次选择多个 `.xls` 或 `.xlsx` 文件。
2. 支持海南大学个人课表导出结构，识别姓名、学号、学期、星期、课程时间与周次，表底附注直接忽略。
   解析以“周次与节次行”（例如 `1-5,7(周)[01-02节]`）为分界，前面的内容作为课程信息，其中最后一行按教师保存，其余行完整保存为课程名称；后面的内容作为地点。支持多行课程名称、分组说明、多行地点与全角括号。同一单元格的多门课程按空行分隔；若边界无法确定但每门课的时间信息有效，则保留时间并显示非阻断的信息提醒。无效周次仍需核实。
3. 正常解析的人员默认参与统计与排班。如果周次、星期和上课时间能够确定，但其他课程信息不完整或多门课程边界不清，会保留上课时间，将无法可靠识别的名称、教师、地点留空，并给出“信息提醒”；这些人员无需确认，仍参与空课表与排班。导入结果、人员列表及详情都能查看提醒。周次或时间无法判断的异常仍需在“查看 / 修改”中核实课程并勾选确认。
4. 重复学号导入会询问是否替换；替换会覆盖该人员手动修改的课程。不同学期的课表不能混合导入同一个工作集。
5. 点“查看 / 修改”可设置校区和部门，也可增加、修改、删除课程。课程可修改名称、星期、周次、起止时间和地点。
6. 多选人员，选择目标默认部门，点“批量修改部门”，选中人员会统一改为此部门。
7. “参与 / 停用”切换选中人员状态，停用人员不参与空闲统计与排班。正常与停用人员混选时，会分别反转各自状态。

部门为办公室、运营采编部、技术部、设计部。导入默认校区为海甸，观澜湖同学需要在人员详情里修改校区。

周次输入支持 `1-9, 12, 14-18`，范围为 1～60。手动课程时间使用 `08:00-09:40` 格式。课程与时段有任何时间重叠，该人员即视为该时段有课。

修改人员、课程或规则后，已有排班会标记过期，请重新生成建议。

## 四、空课表与模板导出

“本周空课表”使用顶部教学周。“总空课表”汇总指定周次，输入范围后点击刷新，每个名字一行，例如 `张三 (1-9, 12, 14-18)`。

点击“导出空课表”下载 Excel：

- 周空课表文件名为 `第3周空课表.xlsx`。
- 总空课表文件名为 `2026-2027学年第1学期校新媒体空课表.xlsx`，学年学期来自导入课表。
- 使用资源目录中的原模板，保留原有工作表、布局、合并单元格、样式与模板标题，仅替换名单区域 C2:I21。
- 两个工作表分别为海甸和观澜湖，运营与采编合并为运营采编部。每名同学一行，沿用模板的仿宋_GB2312 字体样式。
- 模板标题原样保留；上述学期和周次命名指下载文件名。
- 完成后下方显示各校区有内容的名单格数量，便于确认是否导出了内容。

模板只有五个固定节次，**模板导出始终按默认五个节次计算**。页面查看和排班可用自定义时段，Excel 模板不会被改为自定义布局。

项目提供 `public/assets/FangSong_GB2312.ttf` 用于浏览器显示。若另一台电脑在 Excel 中打开时缺少该字体，请右键该文件安装字体，避免 Excel 使用替代字体。大量人员可能超过模板固定行高，模板不会自动增高，请在 Excel 中查看单元格完整内容。

## 五、建议排班与规则

1. 选择教学周，在“班次人数”设置每天、每个时段的人数；0 表示不排班。默认周一到周五的前五个节次各 1 人。
2. 右侧规则面板可展开或隐藏。新增规则支持同时勾选多人，指定星期、时段和周次，空范围表示全部。
3. 禁止安排和固定安排是硬约束。固定规则中的每个人都需要安排进去，人数必须足够，且不能有课、被禁止或与其他班次重叠。冲突时程序报错。
4. 优先安排是软目标。规则从上到下逐项优化，较高优先级的结果会保留；同一规则内的多人属于同一优先级组，并不要求全员同时进入同一格。
5. 自定义优先规则先于默认目标。默认目标依次为满足班次人数、均衡总时长、均衡晚班、均衡周末、减少同一人同日多班。
6. 点击“生成建议排班”。若人手不足，有效方案仍可生成，缺员格会标红。每阶段计算上限约 60 秒；计算时显示加载图标、当前阶段及已用时间，可点击“取消计算”停止并保留原排班；精确优化未完成时，会在有效方案上尝试人员替换与跨班次交换，改善工时、晚班、周末与同日多班的分配，同时遵守硬约束、不降低自定义优先目标、不减少已有名额。界面会注明近似方案，不保证全局最优。复杂人员与规则组合可能需要多阶段计算。
7. 点击排班格，在下拉列表中选择候选人。候选人需无课、未被禁止且不与已有班次重叠；保存时再次检查固定规则和重复人员。
8. 修改格子黄色边框，本次加入的人员绿色背景，超过人均时长加提醒阈值的人员橙色，缺员或冲突红色边框。
9. 支持撤销、重做、恢复最初建议。导出排班下载普通 Excel 表格，包含缺员提示；排班表不使用空课表模板，也不保留界面高亮色。

工时公平按当前教学周计算，当前版本没有跨周累计公平优化。

## 六、自定义时段

顶部“时段设置”可切换默认或自定义时段。自定义每行一项：

```text
上午值班 | 08:00-10:00
下午值班 | 14:30-16:30
晚间值班 | 19:00-21:00
```

支持 1～24 个时段，名称不得重复，结束必须晚于开始。变化会清空排班、重置班次人数、停用指定节次的规则；这些规则的节次范围会清除，需要重新编辑后再启用。课表课程保持原有精确时间，用时间重叠重新计算空闲。

## 七、保存、备份与迁移

数据自动保存到当前浏览器的 localStorage，关掉页面再打开同一地址仍可继续。项目文件夹里不保存人员数据，交付包不含真实学生记录。

- 定期点击“备份数据”，下载完整 JSON，包括人员、课程、规则、时段和排班。
- “恢复数据”会替换当前数据，恢复前先备份。
- 支持读取符合格式的桌面版备份，旧运营部和采编部会统一映射为运营采编部；迁移后应核对人员、时段和规则并重新生成排班。
- 清除浏览器网站数据、换浏览器或使用隐私窗口，会造成数据不可见或丢失。隐私窗口不适合长期使用。
- 浏览器存储容量有限，保存失败时会提示立即备份。多人同时打开页面没有同步机制，请使用一个工作窗口编辑。

此版本不支持多人在线协作、账号共享、云端同步。课表数据不通过静态服务上传。

## 八、维护与重新构建

日常使用无需开发环境。只有修改源码并重新构建时，才需要另外安装带 npm 的 Node.js 开发环境（随包只附带运行文件，不附带 npm）。在项目目录运行：

```powershell
npm ci
npm run build
node tests/engine.test.mjs
```

构建将 `src/app.js`、`src/worker.js` 输出为 `public/app.js`、`public/worker.js`。修改源码后需要重新构建并刷新页面。依赖首次安装需要网络，构建后的页面运行不依赖 CDN。

`tests/browser.mjs` 是开发验证脚本，使用本机 Edge 和已有桌面项目里的样例路径。其他电脑运行前请改为自己的测试课表路径，并先启动本地服务；交付包不附带真实学生样例。

目录说明：

```text
public/                 已构建网页，运行必需
public/assets/          空白 Excel 模板、仿宋字体、图标
src/                    页面、解析/计算/导出与 Worker 源码
server.cjs              仅监听 127.0.0.1 的静态服务
runtime/node.exe        随包附带的 Windows x64 本地服务运行文件
runtime/LICENSE-Node.txt Node.js 与所包含第三方组件的许可
Start-Browser.cmd       一键启动并打开默认浏览器
Stop-Browser.cmd        停止默认端口的后台服务
Create-Shortcut.cmd     生成项目与桌面快捷方式
tests/                  计算与浏览器验证脚本
package-lock.json       固定开发依赖版本
```

## 九、常见问题与系统兼容性

**启动提示缺少运行文件：** 确认已完整解压，且 `runtime/node.exe` 存在。若文件被安全软件隔离，请先核实文件来源，再按本机安全软件提示处理。本包运行时不会自动下载运行环境。

**页面空白或导出失败：** 使用 HTTP 地址打开，确认 `public` 和 `public/assets` 文件齐全。关闭旧标签页后重新打开；修改代码后先重新构建。

**空课表没有某个人：** 核对教学周、该人的参与状态、解析异常确认、校区与部门，以及课程是否与时段重叠。Excel 的海甸和观澜湖名单分别在不同工作表。

**端口占用：** 使用手动部署中的其他端口方法；迁移前后用 JSON 备份恢复。不要误停止其他项目的 Node 服务。

**浏览器选择：** 推荐近期版本的 Edge、Chrome、Firefox。已在 Windows Edge 验证，并检查桌面及 390px 手机视口。手机表格通过容器内横向滚动查看。

**鸿蒙：** 前端使用标准浏览器能力，可作为鸿蒙浏览器适配的基础，但尚未在真实鸿蒙设备验证。Windows 的 `.cmd`、`.ps1` 和快捷方式不能在鸿蒙上运行，鸿蒙设备还需要当地可用的静态 HTTP 服务运行方式。当前服务只允许本机访问，不能用手机访问 Windows 电脑的这个地址。

如只部署网页，可把 `public` 的内容交给其他本地静态服务器，保持所有文件相对路径完整。换访问地址后需恢复 JSON 备份。
